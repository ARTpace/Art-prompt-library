# 标签提示词资产

标签与风格是独立内容类型。`kind: tags` 使用 `pack.json` + 分类 JSON，保留中文名、完整标签、负向提示词及扩展字段；主工具标签接口只读已安装标签包，不回退旧工程数据。

- 原始数据：`data/tag-presets-source/`（本地原件，不进 Git）。
- 发布数据：`libraries/tags/tags-*/`（进 Git）。
- 转换脚本：`python -X utf8 tools/import_tag_presets.py`。
- 统一清单：`python -X utf8 scripts/build_catalog.py`。
- 工具入口：「内容包管理 → 标签包」，支持 GitHub 安装、检查更新、单包更新与卸载。

原库 14 个分类共 22,752 条。保留全部条目，没有去重删除；ID 加分类前缀，原 ID 保存到 `original_id`。同类重复 ID 追加子分类和位置后缀，避免导入器或合并阶段丢失条目。再次转换同一来源得到相同 ID。用户安装后仍在生成界面「标签」页使用，不混入风格页。

质量词、动物、角色特征、服装、姿势动作、摄影、场景背景、光影、特效、物品、其他、现实人物、游戏动漫及 NSFW 各一个包，可按需安装和卸载。默认不自动安装。

旧数据迁移备份位于 `artifacts/backups/retired-prompt-data-20261101/`，含 SHA256 清单，禁止作为主工具回退来源。旧风格 ZIP、画师/角色 ZIP、CCPrompt 停止缓存、旧翻译表、旧海报风格与缩略图均已归档。个人编辑数据不在清理范围。

维护标签后发布变化的包时递增对应版本；不要重置其余包版本。不要把完整提示词转换成单标签，或用风格包替代标签包。
